# Conquering Responsive Layouts

I'm currently taking Kevin Powell’s **21 Day Conquering Responsive Layouts Challenge** to improve my responsive web design skills and build stronger layout foundations.

---

## About the Challenge

This challenge focuses on:

- Building responsive layouts from scratch
- Writing cleaner and more scalable CSS
- Understanding layout techniques like Flexbox
- Improving spacing, sizing, and responsive thinking
