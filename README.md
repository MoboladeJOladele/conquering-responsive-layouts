# Conquering Responsive Layouts

This repository contains my solutions and notes from **Kevin Powell's 21-Day Conquering Responsive Layouts Challenge**.

Although I didn't complete all 21 days, I worked through the course up to **Day 18**, completing the responsive layout projects and strengthening my understanding of modern CSS layout techniques. The course covers 21 days in total and focuses on building responsive layouts with Flexbox, media queries, and mobile-first design.

---

## What I Learned

Throughout the challenge, I practiced:

* Building responsive layouts from scratch
* Writing cleaner, more maintainable CSS
* Using Flexbox to create flexible layouts
* Responsive sizing with relative CSS units
* Working with `width` and `max-width`
* Creating responsive navigation bars
* Designing mobile-first layouts
* Using media queries effectively
* Thinking more intentionally about responsive design
